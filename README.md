# 2026 한국정보사회학회 가을철 정기학술대회 홈페이지

대주제: 불확실성의 시대, AI 전환기의 거버넌스와 후속세대의 미래 · 2026. 11. 28(토) 성균관대학교 호암관

정적 사이트(GitHub Pages) + 접수 백엔드(Google Apps Script)로 구성됩니다.
참가자가 홈페이지에서 신청·제출하면 Apps Script가 구글 드라이브에 자동 저장하고 접수대장 시트에 기록합니다.

```
index.html        홈 (소개, 일정, 학부생 포스터 세션, 자료집 안내, 조직위)
apply.html        신청 / 자료 제출·수정 / 접수 조회
program.html      프로그램 (상태가 '확정'인 건만 자동 표시)
proceedings.html  발제집 전자책 + 발표별 초록(공개 동의 건)
js/config.js      배포 후 고칠 설정 (API 주소, 계좌, 전자책 주소, 문의 메일)
```

## 드라이브 구조 (한국정보사회학회 2026 가을철 학술대회 폴더 안)

| 폴더 / 파일 | 용도 | 공개 |
|---|---|---|
| 초록 | 신청 때 입력한 초록(txt)과 초록 파일 | 조직위 |
| 원문 | 원문·발표자료 파일 (버전별 `_v2`, `_v3`) | **조직위 전용** |
| 발제집 | 11/15 이후 제작할 발제집(PDF 등) | 조직위 → 완성 후 공개 |
| 운영 (조직위 전용) / 접수대장_2026 | 접수 기록(전화·이메일 포함) | **조직위 전용** |
| 이미지 | 포스터·X배너·현수막 | 조직위 |

## 1. Apps Script 설정 (약 10분)

폴더를 소유한 구글 계정으로 로그인한 상태에서 진행합니다.

1. `접수대장_2026` 시트를 열고 **확장 프로그램 → Apps Script**
2. 기본 코드를 지우고 `Code.gs` 전체를 붙여넣기 (폴더·시트 ID는 이미 들어 있음)
3. 맨 위 `CFG`의 `ADMIN_EMAIL`(접수 알림 받을 메일)과 `REPLY_TO`(문의 회신 주소) 입력 (선택)
4. 함수 목록에서 **setup** 선택 → 실행 → 권한 승인 (드라이브, 스프레드시트, 메일)
5. **배포 → 새 배포 → 유형: 웹 앱** → 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포
6. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `js/config.js`의 `API_URL`에 입력

코드를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 갱신해야 URL이 유지됩니다.

## 2. GitHub Pages 게시

1. 새 저장소를 만들고 이 폴더의 파일을 올립니다 (`index.html`이 저장소 맨 위에 오도록).
2. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다. **이 주소가 포스터 QR 주소입니다.**

## 3. 운영

- **접수대장**의 `상태` 열을 `접수 → 검토중 → 확정`으로 바꾸고 `세션`, `시간`을 입력하면 프로그램 페이지에 자동 표시됩니다. `확정`이 아닌 건은 공개되지 않습니다.
- 참가자가 고른 `공개범위`(초록만 / 원문까지 / 공개 안 함)를 따릅니다. `none`이면 초록이 공개되지 않습니다.
- 마감일은 `Code.gs`의 `DEADLINE_APPLY`(신청 11/01), `DEADLINE_FINAL`(파일 제출 11/15, 공지·안내 문구용), `FILES_CLOSE`(파일 실제 접수 종료 11/20, 공지하지 않는 유예), `DEADLINE_EDIT`(제목·초록·저자 수정 11/20)에서 바꿉니다. 안내 문구와 거부 메시지에는 11/15만 보이고, 11/20까지는 늦은 파일도 받습니다.
- **저자 구분**: 신청자는 주저자/공동저자/교신저자 중 본인 구분을 고르고, 함께한 저자(최대 5명)에도 각각 구분을 둡니다. 접수대장 S열(공동저자 `이름(소속)[구분]`), T열(대표 역할), U열(동등 기여 = `동등`)에 저장됩니다.
- **동등 기여**: 체크하면 전원을 가나다순으로 표기하고 “동등 기여, 가나다순”을 덧붙이며, 주저자·공동저자 구분은 숨기고 교신저자만 표시합니다. 프로그램 페이지와 초록 txt가 같은 규칙을 쓰므로, **발제집 최종판도 공개 프로그램(`?action=program`)의 `authors.text`를 그대로 쓰면 순서가 일치합니다.**
- 접수번호는 `2026-P-001`(발표), `2026-D-001`(토론·사회), `2026-U-001`(학부생 포스터) 형식입니다.
- 일반 구글 계정은 메일을 하루 약 100통까지 보낼 수 있습니다.
- 파일은 hwp, hwpx, doc, docx, pdf, ppt, pptx, 8MB 이하만 받습니다.
- **발제집**: 11/15 이후 초록·원문을 모아 PDF로 만들어 `발제집` 폴더에 보관하고, 저장소의 `proceedings/`에 올린 뒤 `config.js`의 `PROCEEDINGS_URL`에 경로를 넣으면 발제집 페이지에 표시됩니다.
- **계좌번호**: `config.js`의 `ACCOUNT`에 은행·계좌·예금주를 넣으면 홈의 “자료집 안내” 아래에 이체 안내가 나타납니다. 비워 두면 보이지 않습니다.

## 4. 권한과 개인정보 (공개 전에 꼭 확인)

- `원문`과 `운영 (조직위 전용)` 폴더는 **조직위원에게만** 공유하세요. 새 파일은 폴더의 공유 설정을 따릅니다.
- 접수대장에는 전화번호와 이메일이 있으므로 조직위 외에는 열람 권한을 주지 마세요.
- 웹 앱 주소는 공개되므로 입력 검증을 넣었습니다: 필수값, 형식, 파일 종류·크기, 중복 신청 차단, 숨김 필드로 스팸 방지, 접수번호+이메일이 맞아야 수정 가능, 모든 칸을 텍스트로 저장(수식 주입 방지).
- 공개 프로그램 데이터에는 성명, 소속, 제목, 초록, 세션, 시간만 나갑니다. 전화·이메일은 나가지 않습니다.
- **개인정보 보유 기간 문구**는 `apply.html`에 `[조직위원회 확정 후 기재]`로 비워 두었습니다. 학회 방침에 맞게 채워 주세요.
